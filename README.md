# Quantitative Finance Book

A Jupyter Book covering option pricing, stochastic volatility, and hedging. Implementations use characteristic function methods (COS, Carr-Madan, CONV), Monte Carlo simulation, and finite differences.

**Read online:** [libapatrik.github.io/Quantitative-Finance-Book](https://libapatrik.github.io/Quantitative-Finance-Book/)
